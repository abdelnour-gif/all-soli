# 🇩🇿 Darja AI: نموذج ونظام خدمة الزبائن بالدارجة الجزائرية

مشروع كامل من جزأين:

1. **النظام الجاهز للخدمة** ([`server/`](server/README.md)): بوت يرد على الزبائن في الموقع وتيليغرام وواتساب
   وماسنجر وإنستغرام، ياخذ الطلبيات والحجوزات، وعندو لوحة تحكم. **يخدم من أول دقيقة بلا نموذج**
   (محرك دارجة مدمج)، وتقدر تربطو بنموذجك المدرَّب.
2. **صناعة النموذج الخاص بك** (هاد المجلد): تعديل (Fine-tuning) نموذج مفتوح المصدر **Qwen2.5-3B**
   على الدارجة، مجاناً على Google Colab.

```
generate_data.py ← train_colab.ipynb (Colab) ← darja.gguf ← Ollama ← server/ (LLM_PROVIDER=ollama)
        ▲                                                                   │
        └──────────── المحادثات الحقيقية المصحّحة (تصدير من لوحة التحكم) ◄────┘
```

👉 **باش تبدا دغيا:** روح لـ [`server/README.md`](server/README.md).

## محتوى المجلد

| الملف | الاستعمال |
|---|---|
| `generate_data.py` | يولّد بيانات التدريب: أسئلة الزبائن بالدارجة مع الردود المثالية |
| `data/train.jsonl` و `data/test.jsonl` | البيانات الجاهزة: 1900 مثال للتدريب (منهم محادثات بجوج أدوار) و100 للاختبار |
| `data/my_examples.example.jsonl` | نموذج لكيفية إضافة محادثاتك الحقيقية |
| `train_colab.ipynb` | ملف التدريب، تفتحه في Google Colab |
| `Modelfile` | لتشغيل النموذج على حاسوبك بـ Ollama |
| `server/` | النظام الكامل: البوت، لوحة التحكم، القنوات |

## الخطوات

### 1. (اختياري) أضف أمثلتك الحقيقية
هذا أهم شيء لتحسين النموذج. انسخ `data/my_examples.example.jsonl` إلى `data/my_examples.jsonl`،
وأضف محادثات حقيقية من محلات تعرفها، مثالاً في كل سطر. بعدها أعد توليد البيانات:
```bash
python3 generate_data.py
```
يمكنك أيضاً إضافة محلات وأسئلة جديدة مباشرة داخل `generate_data.py`: القائمة `SHOPS` والدوال `intent_*`.

### 2. التدريب على Google Colab (مجاني)
1. ادخل إلى colab.research.google.com ← `File` ← `Upload notebook` ← اختر `train_colab.ipynb`.
2. `Runtime` ← `Change runtime type` ← **T4 GPU**.
3. شغّل الخلايا بالترتيب، وعندما يطلب منك ارفع `train.jsonl` و `test.jsonl`.
4. في النهاية يُحمَّل ملف `.gguf`، وهذا هو نموذجك 🎉

يأخذ التدريب تقريباً من 20 إلى 40 دقيقة.

### 3. التشغيل على حاسوبك
1. ثبّت Ollama من ollama.com.
2. ضع ملف `.gguf` بجانب `Modelfile` وسمّه `darja.gguf`.
3. بدّل معلومات المحل داخل `Modelfile` بمعلومات محلك.
4. نفّذ:
```bash
ollama create darja -f Modelfile
```
```bash
ollama run darja
```

## كيف يعمل؟

كل مثال تدريب فيه 3 أجزاء:
- **system**: بطاقة معلومات المحل (الأسعار، التوصيل، الأوقات...).
- **user**: سؤال الزبون بالدارجة.
- **assistant**: الرد المثالي المبني على البطاقة فقط.

بهذه الطريقة يتعلم النموذج قراءة معلومات **أي محل** والرد منها، ولهذا لا تحتاج إلى تدريب نموذج جديد لكل زبون.
تبدّل البطاقة فقط.

## الأسئلة التي يتعلمها
السعر، التوفر، المقاسات، التوصيل، الأوقات، العنوان، الدفع، الترجيع والضمان، أخذ الطلبيات وحجز المواعيد،
التحية والشكر، الشكاوى، الأسئلة التي ليس عنده جوابها (يحيل الزبون إلى رقم المحل بدل أن يخترع جواباً)،
والأسئلة الخارجة عن الموضوع.
