# QueuePro — منصة الطوابير الرقمية (الإصدار 2.1.0)

منصة متعددة المزوّدين لإدارة الطوابير بأرقام تتابعية (بدون مواعيد):
**العميل ينضم ← يأخذ رقماً ← يتابع موقعه ← يُخدم.**
بدون حساب للعميل، وبدون بوابة دفع. واجهة للهاتف أولاً، عربية (RTL) وإنجليزية (LTR).

يأتي المشروع **بنسختين من نفس الكود** (نفس المحرك ونفس الجداول ونفس الاختبارات):

| النسخة | الملف | متى تستخدمها |
|---|---|---|
| **إضافة ووردبريس** (Custom Plugin) | `queuepro-wordpress-plugin.zip` | عندك موقع ووردبريس، أو تريد إدارة الاستضافة من ووردبريس. الجداول الخاصة `qp_*` داخل قاعدة بيانات ووردبريس نفسها. |
| **نسخة مستقلة** | `queuepro-standalone.zip` | استضافة PHP عادية بدون ووردبريس (أخف وأسرع). قاعدة SQLite جاهزة أو MySQL. |

> لإنشاء الملفين من الكود: `php bin/build.php` ← يظهران في مجلد `dist/`.

---

## 1) التثبيت كإضافة ووردبريس (5 دقائق)

1. لوحة ووردبريس ← **إضافات ← أضف جديد ← رفع إضافة** ← اختر `queuepro-wordpress-plugin.zip` ← **التنصيب الآن** ← **تفعيل**.
2. **الإعدادات ← الروابط الدائمة** ← اختر "اسم المقالة" (Post name) ← حفظ. (ضروري لروابط مثل `/dashboard/` و`/اسم-المزوّد/`).
3. من القائمة الجانبية ← **QueuePro** ← تأكد أن كل المتطلبات ✓ ← أدخل اسم المنصة وحساب **المدير العام (Super Admin)** ← **تثبيت المنصة**.
4. افتح `https://موقعك/super-admin/` وادخل بالحساب الذي أنشأته.

ملاحظات ووردبريس:
- حسابات المنصة (المدير والمزوّدون) **منفصلة عن حسابات ووردبريس**: المزوّد لا يرى لوحة ووردبريس أبداً.
- صفحة **QueuePro** في ووردبريس فيها: الروابط، خيار "عرض المنصة على الصفحة الرئيسية" (ألغِه إن أردت إبقاء صفحة ووردبريس الرئيسية)، خيار Cloudflare، و**استعادة كلمة مرور المدير العام**.
- صفحات ووردبريس العادية تبقى تعمل. إذا كان لمزوّد نفس رابط صفحة ووردبريس، فصفحة المزوّد هي التي تظهر.
- الملفات الخاصة في `wp-content/queuepro-data` والصور في `wp-content/uploads/queuepro`، فتحديث الإضافة أو حذفها **لا يحذف أي بيانات**.
- على Nginx: انسخ قسم WordPress من `docs/nginx.conf`.

## 2) التثبيت كنسخة مستقلة (بدون ووردبريس)

1. ارفع `queuepro-standalone.zip` إلى `public_html` (أو مجلد فرعي) وفك الضغط، ثم انقل محتوى المجلد `queuepro/` إلى المكان الذي تريده.
2. PHP 8.0 أو أحدث، مع إضافة `pdo_sqlite` (أو `pdo_mysql`). صلاحيات 755 لمجلدي `storage` و`uploads`.
3. افتح رابط موقعك ← صفحة التثبيت ← اسم المنصة وحساب المدير ← "تثبيت المنصة".
4. فعّل شهادة SSL (HTTPS) من لوحة الاستضافة.

> ملفات الحماية `.htaccess` موجودة في الحزمة، وإذا ضاعت أثناء الرفع (بعض مدراء الملفات يتجاهل الملفات التي تبدأ بنقطة) **تُعيد المنصة إنشاءها تلقائياً** عند أول زيارة.

## 3) الروابط

| الرابط | الاستخدام |
|---|---|
| `/` | الصفحة الرئيسية |
| `/explore/` | استكشاف المزوّدين (بحث بالتصنيف والمدينة) |
| `/{رابط-المزوّد}/` | صفحة المزوّد والحجز (مثال: `/salon-elegance/`) |
| `/t/...` | تذكرة العميل (رابط سري خاص به) |
| `/dashboard/` | لوحة المزوّد (للهاتف) |
| `/super-admin/` | لوحة الإدارة |

## 4) كيف يعمل بدون حساب للعميل؟

- العميل يكتب **رقم هاتفه فقط** ← يحصل على رقم في الطابور و**رابط سري** (`/t/...`) هو هويته. المنصة لا تحفظ إلا بصمة (hash) الرابط.
- **"كم أمامي"** = عدد التذاكر المنتظرة عند نفس المزوّد في نفس اليوم وترتيبها قبل تذكرته. الوقت التقريبي = العدد × متوسط مدة الخدمة. يتحدّث تلقائياً كل 7 ثوانٍ.
- **حجز نشط واحد لكل رقم هاتف** عند نفس المزوّد (مضمون في قاعدة البيانات).
- إذا أضاع العميل الرابط: يسترجعه من صفحة المزوّد برقم هاتفه ورمز تحقق (عند تفعيل الرسائل).
- **الرصيد (Credit) على المزوّد وليس على العميل.**

## 5) الرصيد (Credits)

- كل مزوّد جديد: **10 حجوزات مجانية**.
- عند الحجز يُحجز Credit (Reserved)، ويُخصم فعلياً **فقط عند "إكمال الخدمة"**. الإلغاء والغياب يُرجعان الرصيد (Released).
  تغيير السياسة: الإعدادات ← "خصم عند الغياب" / "خصم عند الإلغاء".
- المتاح = (المنحة + المشتراة + التعديلات) − المحجوز − المستهلك، **ولا يصبح سالباً أبداً**.
- عند المتاح = 0: يتوقف الحجز الجديد فقط مع رسالة للعملاء، ويكمل المزوّد خدمة من في الطابور، ويعود الحجز **تلقائياً** بعد الشحن.
- كل حركة تُسجَّل في **سجل الرصيد (Ledger)**: النوع، الرصيد بعدها، السبب، ومعرّف المدير.
- التذاكر التي تبقى "في الانتظار" عند نهاية اليوم (بتوقيت المزوّد) تُنهى تلقائياً ويُرجع رصيدها.

## 6) الاستخدام اليومي

**المدير العام (`/super-admin/`):**
- **مزوّد جديد:** المزوّدون ← مزوّد جديد. تظهر بيانات دخوله **مرة واحدة** فسلّمها له.
- **شحن الرصيد:** صفحة المزوّد ← اختر الباقة (مثلاً 150) وطريقة الدفع وملاحظة ← إضافة رصيد. تُدار الباقات من "الباقات".
- **تجميد / حظر** مزوّد، عرض حجوزاته وسجل رصيده، و**سجل العمليات (Audit Log)** لكل العمليات الحساسة.
- **نسي المزوّد كلمة المرور:** صفحة المزوّد ← "إنشاء كلمة مرور جديدة".

**المزوّد (`/dashboard/` من هاتفه):** يرى رصيده (متاح / محجوز / مستهلك) مع تنبيه عند 5 أو أقل، يفتح ويغلق الطابور، يدير الطابور بالأزرار (نداء، بدء الخدمة، تأجيل مرة واحدة، إكمال، غياب، إلغاء)، يضيف عميلاً حاضراً بدون هاتف (Walk-in)، يدير خدماته وأسعاره وصوره، ويطبع رمز QR لباب المحل.

**العميل:** يفتح رابط المزوّد أو يمسح رمز QR ← رقم هاتفه ← "احجز دورك" ← يتابع دوره ويستطيع الإلغاء من نفس الصفحة.

## 7) الحماية من الحجز العشوائي (بدون إزعاج الزبائن الحقيقيين)

كثير من الزبائن يتشاركون نفس عنوان IP (شبكة Wi-Fi المحل، أو شبكة الهاتف المحمول)، لذلك لا تُرفض الشبكة بعد عدد صغير من الحجوزات. الحماية على طبقات:

| الطبقة | الافتراضي | ماذا يحدث |
|---|---|---|
| لكل هاتف / متصفح | 3 حجوزات كل 15 دقيقة | هاتف واحد لا يستطيع حجز أرقام كثيرة، حتى لو غيّر الشبكة. |
| لكل شبكة (حد عادي) | 6 حجوزات كل 15 دقيقة | بعدها **لا يُرفض الزبون**: يُطلب منه رمز تحقق SMS يصله على هاتفه ثم يكمل الحجز. السكربت الذي يخترع أرقاماً لا يستطيع تجاوزه. |
| لكل شبكة (سقف نهائي) | 30 حجزاً كل 15 دقيقة | حد أقصى ضد الإغراق، حتى عندما لا تكون بوابة الرسائل مفعّلة. |
| لكل رقم هاتف | 6 حجوزات يومياً + حجز نشط واحد عند نفس المزوّد | |

- تُحسب **الحجوزات الناجحة فقط**: رقم مكتوب خطأً لا يأخذ مكان أحد.
- معرّف الهاتف رقم عشوائي محفوظ في المتصفح فقط (بدون كوكيز وبدون بيانات شخصية).
- **بدون بوابة SMS** (الوضع الافتراضي "سجل فقط") لا توجد خطوة الرمز، فيعمل الحد لكل هاتف والسقف النهائي فقط. لأفضل حماية فعّل بوابة الرسائل.
- كل الأرقام قابلة للتعديل من لوحة الإدارة ← الإعدادات ← "الحماية من الإساءة".

## 8) رسائل SMS / واتساب

الافتراضي "سجل فقط" (لا يُرسل شيء). من الإعدادات ← بوابة الرسائل: "بوابة HTTP عامة" (أي مزوّد SMS) أو Twilio (SMS أو واتساب). جرّب من صفحة الرسائل ← "إرسال رسالة تجريبية"، ثم فعّل رمز التحقق عند الحجز إن أردت.

## 9) النسخ الاحتياطي (مهم)

- لوحة الإدارة ← الإعدادات ← **"تنزيل نسخة احتياطية"** (أسبوعياً على الأقل).
- **نسخة ووردبريس:** البيانات في قاعدة بيانات ووردبريس (جداول `qp_*`)، فأي إضافة نسخ احتياطي لووردبريس تشملها. وانسخ أيضاً `wp-content/uploads/queuepro`.
- **النسخة المستقلة:** كل البيانات في `storage/database.sqlite` و`storage/config.php` ومجلد `uploads`. للاسترجاع: ضع ملف النسخة مكان `storage/database.sqlite`.

## 10) نسيت كلمة مرور المدير العام

- **ووردبريس:** لوحة ووردبريس ← QueuePro ← "استعادة دخول المدير العام".
- **مستقلة:** أنشئ ملف `storage/recover.txt` واكتب فيه رمزاً (8 أحرف أو أكثر)، ثم افتح `/recover-admin`. يُحذف الملف تلقائياً بعد الاستخدام.

## 11) الأمان

- الأدوار: مدير عام، مزوّد (يرى بياناته فقط)، عميل (تذكرته فقط عبر رابطه السري).
- كلمات مرور مشفّرة، وحماية من CSRF وXSS وSQL Injection وIDOR والطلبات المكررة (ضغطتان متتاليتان لا تنشئان حجزين)، وحد لمحاولات الدخول والحجز.
- الترقيم داخل Transaction مع قفل الصفوف: لا تكرار للأرقام ولا خصم مزدوج حتى مع حجوزات متزامنة.
- المجلدات الخاصة محمية بـ `.htaccess` (Apache / LiteSpeed). على Nginx استخدم `docs/nginx.conf`.
- لوحة الإدارة ← الإعدادات ← **"حالة النظام"**: تفحص الحماية والصلاحيات وتوازن الأرصدة.

## 12) الاختبارات

```
php tests/acceptance.php                                   127 اختباراً للمحرك (SQLite)
QP_TEST_DRIVER=mysql QP_DB_USER=.. QP_DB_PASS=.. QP_DB_NAME=.. php tests/acceptance.php    نفسها على MySQL
php tests/e2e_http.php https://موقعك ADMIN_USER 'PASSWORD' [--standalone]                  فحص موقع يعمل فعلاً عبر HTTP
```
اختبار `e2e_http.php` ينشئ مزوّدَين للتجربة (`e2e-...`)، فشغّله على نسخة تجريبية وليس على الموقع الحقيقي.

## 13) أدوات سطر الأوامر (SSH، اختيارية)

```
php bin/console.php check                   فحص النظام وتوازن الأرصدة
php bin/console.php backup                  نسخة احتياطية
php bin/console.php reset-password USER     كلمة مرور جديدة لأي حساب
php bin/console.php cron                    (اختياري) كل 5 دقائق من Cron
php bin/build.php                           إنشاء ملفي ZIP للنسختين في dist/
```
في نسخة ووردبريس تعمل نفس الأوامر من `wp-content/plugins/queuepro/bin/console.php`، ومهمة الصيانة تعمل تلقائياً عبر WP-Cron كل 5 دقائق.

## 14) التسليم والملكية

- الكود كاملاً مع مخطط قاعدة البيانات (`app/Database/Schema.php`) والاختبارات والتوثيق.
- لا يوجد في الكود أي حساب أو مفتاح أو رابط خاص بالمطوّر. مفتاح التشفير يُولَّد عشوائياً عند التثبيت على خادمك.
- سجّل الدومين والاستضافة **باسمك**، وأنشئ مفاتيح بوابة الرسائل (API Keys) من حسابك، وأدخلها من لوحة الإدارة ← الإعدادات.
- بعد التسليم: غيّر كل كلمات المرور (الاستضافة، ووردبريس، المدير العام) واحذف أي حساب للمطوّر.

## 15) قاعدة بيانات جاهزة للتوسع

جداول جاهزة للدول والمدن والعملات والمناطق الزمنية واللغات (`qp_countries`, `qp_cities`, `qp_currencies`, `qp_languages`)، ولكل مزوّد منطقة زمنية وعملة خاصة. تُفعَّل لاحقاً بدون تغيير البنية.
