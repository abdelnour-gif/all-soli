# QueuePro — منصة الطوابير الرقمية (PHP + SQLite)

نسخة مستقلة بالكامل بدون ووردبريس. الإصدار 2.0.0.

## التثبيت (5 دقائق)
1. ارفع محتوى المجلد إلى الاستضافة (public_html أو مجلد فرعي) عبر مدير الملفات أو FTP، ثم فك الضغط.
2. تأكد أن PHP 8.0 أو أحدث، وأن إضافة pdo_sqlite مفعّلة (لوحة الاستضافة ← Select PHP Version).
3. صلاحيات 755 لمجلدي `storage` و `uploads`.
4. افتح رابط موقعك ← تظهر صفحة التثبيت ← أدخل اسم المنصة وحساب المدير ← "تثبيت المنصة".
5. فعّل شهادة SSL المجانية (HTTPS) من لوحة الاستضافة.

## الروابط
| الرابط | الاستخدام |
|---|---|
| `/` | الصفحة الرئيسية |
| `/explore/` | استكشاف المزوّدين |
| `/{رابط-المزوّد}/` | صفحة المزوّد والحجز (مثال: `/salon-elegance/`) |
| `/t/...` | تذكرة العميل |
| `/dashboard/` | لوحة المزوّد (للهاتف) |
| `/super-admin/` | لوحة الإدارة |

## الاستخدام اليومي
- **إضافة مزوّد:** لوحة الإدارة ← المزوّدون ← مزوّد جديد. تظهر بيانات دخوله مرة واحدة فسلّمها له. يحصل على 10 حجوزات مجانية.
- **شحن الرصيد:** صفحة المزوّد ← اختر الباقة وطريقة الدفع ← إضافة رصيد.
- **نسي المزوّد كلمة المرور:** صفحة المزوّد ← "إنشاء كلمة مرور جديدة".
- **المزوّد:** يدخل `/dashboard/` من هاتفه، يضيف خدماته وصوره، ويطبع رمز QR لباب المحل، ويدير الطابور بالأزرار.
- **العميل:** يفتح رابط المزوّد ← رقم هاتفه ← "احجز دورك" ← يتابع دوره تلقائياً بدون حساب.

## النسخ الاحتياطي (مهم)
- الإعدادات ← "تنزيل نسخة احتياطية" (أسبوعياً على الأقل).
- الاسترجاع: ضع ملف النسخة مكان `storage/database.sqlite`.
- كل بياناتك في: `storage/database.sqlite` + `storage/config.php` + مجلد `uploads`.

## رسائل SMS / واتساب
الافتراضي "سجل فقط" (لا يُرسل شيء). من الإعدادات ← بوابة الرسائل: اختر "بوابة HTTP عامة" (أي مزوّد SMS) أو Twilio (SMS/واتساب)، ثم جرّب من صفحة الرسائل ← "إرسال رسالة تجريبية"، وبعدها فعّل رمز التحقق عند الحجز.

## نسيت كلمة مرور المدير
أنشئ ملف `storage/recover.txt` من مدير الملفات واكتب بداخله رمزاً (8 أحرف أو أكثر)، ثم افتح `/recover-admin` وأدخل الرمز وكلمة المرور الجديدة. يُحذف الملف تلقائياً.

## الأمان
- مجلدات `storage` و `app` و `bin` و `tests` و `templates` محمية بملفات `.htaccess` (Apache / LiteSpeed). على Nginx استخدم `docs/nginx.conf`.
- كلمات المرور مشفّرة، حماية CSRF وXSS وSQL Injection وIDOR، حد لمحاولات الدخول، والمزوّد لا يرى إلا بياناته.
- من الإعدادات ← "حالة النظام" تتأكد أن كل شيء سليم.

## أدوات اختيارية (SSH)
```
php bin/console.php check            فحص النظام وتوازن الأرصدة
php bin/console.php backup           نسخة احتياطية
php bin/console.php reset-password USER
php bin/console.php cron             (اختياري) كل 5 دقائق من Cron
```

## التحويل إلى MySQL لاحقاً
اختر MySQL عند التثبيت للمنصات الكبيرة جداً. SQLite يكفي لآلاف العملاء يومياً.
